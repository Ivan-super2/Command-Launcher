# COMMAND LAUNCHER

### Графический центр управления командами, ботами VK и Telegram

Настольное приложение для Linux, предназначенное для запуска пользовательских команд, управления ботами ВКонтакте и Telegram, а также работы с прокси-соединениями Telegram.

## 1. О проекте

**Command Launcher** — графическое приложение для операционной системы Linux, позволяющее запускать пользовательские команды и управлять различными инструментами из единого рабочего пространства.

Программа разработана на языке Python с использованием библиотеки PySide6 (Qt6).

Основная задача проекта — предоставить пользователю удобный графический интерфейс для работы с командами терминала, ботами социальных платформ и дополнительными сетевыми инструментами.

В приложении объединены следующие возможности:

- создание и запуск собственных команд через графические кнопки;
- работа с интерактивным терминалом;
- подключение и управление ботом ВКонтакте;
- подключение и управление ботом Telegram;
- отдельный менеджер прокси-соединений для Telegram;
- настройка внешнего вида приложения;
- управление фоновыми процессами и системной службой.

Программа ориентирована на пользователей, которым необходимо регулярно выполнять команды терминала, управлять ботами и контролировать работу нескольких инструментов в одном приложении.

## 2. Основные возможности

### 2.1. Пользовательские команды и терминал

В приложении предусмотрена система пользовательских команд, позволяющая создавать собственные кнопки для выполнения часто используемых операций.

Пользователь может:

- создавать кнопки с произвольным названием;
- указывать команду, которая будет выполняться при нажатии;
- выбирать цвет кнопок;
- редактировать уже созданные команды;
- удалять ненужные кнопки;
- изменять порядок расположения кнопок;
- запускать команды в отдельной рабочей области терминала;
- просматривать результаты выполнения команд;
- отслеживать сообщения об ошибках;
- работать с интерактивным выводом терминала.

Также предусмотрена возможность создания кнопки на основе выбранной команды терминала, если соответствующий сценарий поддерживается текущей реализацией приложения.

### 2.2. Бот ВКонтакте

В приложении реализована интеграция с платформой ВКонтакте, позволяющая подключать и управлять ботом сообщества.

Для подключения используются токен сообщества и идентификатор группы.

Основные возможности:

- подключение бота сообщества ВКонтакте;
- настройка токена и идентификатора группы;
- формирование клавиатуры команд на основе настроенных действий;
- обработка пользовательских действий;
- выполнение соответствующих команд;
- просмотр журнала событий VK;
- очистка журнала событий;
- управление запуском бота;
- настройка параметров работы бота.

Для удобства работы события ВКонтакте отображаются в отдельном журнале, что позволяет отслеживать действия пользователей и работу бота независимо от остальных компонентов программы.

### 2.3. Бот Telegram

Программа поддерживает подключение и управление Telegram-ботом с использованием токена, полученного через BotFather.

Основные возможности:

- подключение Telegram-бота;
- настройка токена бота;
- формирование клавиатуры команд на основе пользовательских кнопок;
- обработка команд и сообщений пользователей;
- выполнение настроенных действий;
- просмотр отдельного журнала Telegram;
- очистка журнала событий;
- настройка автоматического запуска;
- настройка файлового логирования;
- управление работой Telegram-бота.

Логирование Telegram организовано отдельно от других журналов приложения. Это позволяет просматривать события бота независимо от настроек записи логов в файлы.

Важной особенностью является разделение сетевой логики Telegram и ВКонтакте. Настройки прокси предназначены для Telegram и не должны автоматически перенаправлять через прокси трафик бота ВКонтакте или других приложений.

### 2.4. Менеджер прокси Telegram

В приложении предусмотрен отдельный менеджер прокси-соединений, предназначенный для настройки сетевого подключения Telegram-бота.

Пользователь может хранить несколько конфигураций прокси и выбирать необходимую для использования.

Поддерживаемые возможности:

- добавление нескольких прокси-конфигураций;
- выбор активного прокси;
- поддержка SOCKS4;
- поддержка SOCKS5;
- поддержка HTTP;
- использование Xray для работы с соответствующими конфигурациями;
- поиск исполняемых файлов Xray и V2Ray;
- импорт конфигураций;
- экспорт конфигураций в JSON;
- индивидуальная проверка прокси;
- проверка всех добавленных прокси;
- отображение результатов проверки и задержки соединения;
- автоматический выбор подходящего прокси на основе результатов проверок.

Также предусмотрена обработка различных форматов конфигураций и ссылок:

- VLESS;
- VMess;
- Trojan;
- Shadowsocks;
- JSON-конфигурации;
- YAML-конфигурации;
- Base64-подписки;
- веб-страницы, содержащие данные подписок.

Менеджер прокси предназначен именно для Telegram. Использование прокси не должно затрагивать работу других приложений, системных подключений и бота ВКонтакте.

### 2.5. Настройки, темы и фоновая работа

Приложение содержит отдельную систему настроек, позволяющую управлять внешним видом и параметрами работы программы.

Настройки сохраняются локально в пользовательской директории:

```text
~/.config/mycommandlauncher/
```

Основные возможности:

- сохранение пользовательских настроек;
- использование тёмной темы по умолчанию;
- переключение на светлую тему;
- настройка пользовательского оформления;
- настройка параметров ботов;
- управление логированием;
- настройка автоматического запуска;
- работа через системный трей;
- скрытие главного окна без завершения работы приложения;
- продолжение работы фоновых компонентов после скрытия окна.

Также предусмотрена возможность управления пользовательской системной службой systemd.

Служба предназначена для выполнения фоновых задач и может использоваться для запуска и управления компонентами приложения без необходимости постоянно держать открытым главное окно.

Предусмотрены операции:

- создание пользовательской службы;
- запуск службы;
- остановка службы;
- перезапуск службы;
- настройка автоматического запуска.

## 3. Используемые технологии

Для разработки Command Launcher используются следующие технологии и библиотеки:

| Технология | Назначение |
|---|---|
| Python 3 | Основной язык программирования |
| PySide6 / Qt6 | Создание графического интерфейса |
| vk-api | Взаимодействие с API ВКонтакте и Long Poll |
| pyTelegramBotAPI | Работа с Telegram Bot API |
| requests | Выполнение HTTP-запросов |
| PySocks | Поддержка SOCKS-прокси |
| Xray / V2Ray | Работа с соответствующими прокси-конфигурациями |
| systemd | Управление пользовательской фоновой службой |

## 4. Установка и запуск

### 4.1. Требования

Для работы программы необходимы:

- операционная система Linux;
- установленный Python версии 3;
- возможность создания виртуального окружения;
- доступ к установке Python-библиотек;
- графическая среда с поддержкой Qt6.

Для отдельных функций может потребоваться дополнительный компонент Xray или V2Ray.

### 4.2. Создание виртуального окружения

Перейдите в директорию проекта и выполните:

```bash
python3 -m venv venv
```

Активируйте виртуальное окружение:

```bash
source venv/bin/activate
```

Обновите pip:

```bash
python -m pip install --upgrade pip
```

### 4.3. Установка зависимостей

Установите основные библиотеки:

```bash
pip install PySide6 vk-api pyTelegramBotAPI "requests[socks]"
```

Дополнительно установите:

```bash
pip install PyYAML
```

### 4.4. Запуск программы

После установки зависимостей запустите приложение:

```bash
python command_launcher.py
```

## 5. Настройки и безопасность

Command Launcher использует локальные настройки, которые хранятся в пользовательской директории:

```text
~/.config/mycommandlauncher/config.json
```

В настройках могут находиться чувствительные данные:

- токены VK;
- токены Telegram;
- пароли для выполнения привилегированных команд;
- параметры прокси-соединений;
- адреса серверов;
- другие пользовательские данные.


Перед загрузкой проекта необходимо:

1. Проверить исходный код на наличие токенов и паролей.
2. Удалить реальные IP-адреса и данные прокси, если они не предназначены для публикации.
3. Не добавлять пользовательский `config.json` в репозиторий.
4. Не публиковать журналы, содержащие персональные данные.
5. Не размещать приватные ссылки на прокси-подписки.
6. Добавить файл `.gitignore`.
7. При необходимости подготовить пример конфигурации без секретных данных.

Отдельное внимание необходимо уделить выполнению команд терминала.

Приложение позволяет запускать пользовательские команды, в том числе требующие повышенных привилегий через `sudo` или `su`, в зависимости от используемого окружения.

Пользователь должен запускать только известные и проверенные команды. Наличие графического интерфейса не отменяет необходимости проверять безопасность выполняемых операций.
